How many glasses are in a bottle of wine?

Foundation guide · Beginner friendly · Australian context

Highlights

  • A typical 750 mL bottle makes about five glasses if each pour is 150 mL.
  • Smaller 125 mL pours produce six glasses.
  • A 100 mL pour gives 7.5 theoretical pours.
  • Larger pours produce fewer glasses.
  • The calculation is simple: bottle volume ÷ pour size.
  • A wine glass’s physical capacity is not the same as the amount you should pour into it.
  • A glass of wine is not automatically the same as an Australian standard drink.

Quick answer

A typical bottle of still wine contains 750 mL. At a 150 mL pour, that gives:

750 mL ÷ 150 mL = 5 glasses

So, the practical answer is about five glasses per bottle when using 150 mL pours.

There is no single universal number, though. If you pour 125 mL into each glass, the same bottle gives six glasses. If you pour generously, you may get only four full glasses, with a little wine left.

How many glasses does a 750 mL bottle make?

Pour size Approximate result
100 mL 7.5 pours
125 mL 6 pours
150 mL 5 pours
175 mL About 4.3 pours

These are volume calculations, not guarantees. They assume the bottle is completely emptied and every pour is the same size.

The 150 mL example is a useful planning reference because the Australian Government’s standard-drinks guide gives 150 mL as an example average restaurant serving. Wine education guidance also uses 150 mL when estimating five servings from a 750 mL bottle.

Why can the number vary?

The biggest variable is pour size. A generous pour uses more wine, so the bottle runs out sooner. Smaller pours stretch the bottle further.

A “glass” also means the amount poured, not the maximum capacity of the glass itself. Wine glasses can hold considerably more than 150 mL and are not normally filled to the rim. For more on the difference between glass shape, capacity and serving, see Wine Glass Types Explained.

Small practical losses can affect the final result too. Wine may be spilled, left with sediment, used to top up another glass or divided unevenly between people. Sparkling wine may also be poured with extra space at the top to manage its bubbles.

Bottle size matters as well. A 750 mL bottle is the common reference format, but wine is also sold in smaller and larger bottles. The same formula applies:

bottle volume ÷ pour size = approximate number of glasses

What about Australian standard drinks?

A poured glass and a standard drink are different measurements.

Australian standard-drink guidance defines one standard drink as containing 10 grams of pure alcohol. The number of standard drinks in a glass depends on both the amount poured and the wine’s alcohol concentration. That means a 150 mL glass is not automatically one standard drink.

Australian Government guidance uses 100 mL as an example standard wine serve at specified alcohol concentrations, while also showing 150 mL as an average restaurant serving. These figures describe different things, so they should not be treated as competing universal pour rules.

If you are tracking alcohol, check the approximate standard-drink number on the bottle label rather than counting glasses.

Does sparkling wine make more glasses?

It may. Sparkling wine is often served in smaller pours; WSET uses approximately 125 mL as a usual reference in its serving guidance. At that size, a 750 mL bottle gives six theoretical pours.

Actual service varies between households and venues, so treat six as an estimate rather than a promise.

Frequently asked questions

Is five glasses the standard answer for a bottle of wine?

It is the most useful quick answer when assuming five 150 mL pours from a 750 mL bottle. Smaller or larger pours change the result.

Is a 750 mL bottle enough for six people?

Only if each person receives a 125 mL pour, and even then it is a calculation rather than a guarantee. For wider event planning, use the party wine guide.

Is one glass of wine one standard drink?

No. A standard drink is based on 10 grams of pure alcohol. The alcohol percentage and pour size both affect how many standard drinks are in a glass.
